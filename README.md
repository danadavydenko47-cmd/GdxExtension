# GDX Extension v3.1 — by dnl8272

Упрощённый менеджер модов для Geometry Dash (Geode).

## Что изменилось в 3.1
- Каталог модов **встроен в код мода** — открывается мгновенно, работает офлайн, 404 невозможен.
- Для добавления модов в каталог: открой `src/main.cpp`, массив `CATALOG`, скопируй строку-образец:
  `{"Название", "автор", "описание", "https://прямая-ссылка/файл.geode"}`
- ВАЖНО: ссылка должна быть ПРЯМОЙ (ссылка на сам файл, а не на страницу релиза).
  Прямая ссылка из GitHub: Releases → правый клик по файлу → Copy link.

## Запуск
1. Залей всё содержимое в репозиторий GitHub (включая скрытую папку `.github`).
2. Вкладка Actions → сборка → скачай артефакт.
3. Файл `GdxExtension.geode` → `Android/media/com.geode.launcher/game/geode/mods/`
4. Полностью перезапусти GD.

## Структура
- Личная папка модов: `Android/media/com.geode.launcher/game/geode/mods/dnl.gdx_extension/save/gdx/`
  (создаётся автоматически при первом запуске)
- Формат `.gdx`: обычный ZIP c `manifest.json` внутри (название, автор, версия) + файлы (текстуры/звуки/темы).
- Панель владельца доступна только аккаунту `dnl8272`.
